# DåseØl

Android-app med hjemmeskærms-widget, der viser det billigste tilbud på øl på dåse inden for en valgt afstand.

- Visning: pris pr. 18 stk, pr. 24 stk eller literpris
- Vælg mærker (Carlsberg, Tuborg, Royal, Heineken, Harboe …)
- Position: telefonens GPS eller en fast adresse/postnummer
- Data: eTilbudsavis (Tjek) – opdateres hver 3. time og ved tryk på ⟳

APK'en bygges af GitHub Actions; hver push giver en release `build-N` med `DaaseOel.apk`.
